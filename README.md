## 💼 Projetos em Destaque

### 🌟 [Corte e Poda](https://github.com/pikulitomarkin/corte-poda)
> Sistema web para gerenciamento de atividades de corte e poda de vegetação com controle de usuários e monitoramento em tempo real.

**🛠️ Stack:** React • Firebase • Rest API • CSS3

**✨ Destaques:**
- 🔐 Sistema de autenticação com níveis de acesso
- ☁️ Sincronização em tempo real com Firebase
- 📊 Dashboard com estatísticas e progresso visual
- 📱 Interface responsiva e moderna

---

### 🎯 [Onde a Linha Desligou - Web Debug](https://github.com/pikulitomarkin/onde_a_linha_desligou_web_debug)
> Aplicação web para consulta e visualização de torres de transmissão elétrica com localização por quilometragem e mapa interativo.

**🛠️ Stack:** Python • Flask • Railway • JavaScript

**✨ Destaques:**
- 🗺️ Consulta inteligente de torres por KM
- 📍 Visualização detalhada com mapas interativos
- 🌐 Deploy na nuvem com Railway
- 📊 Suporte a múltiplas linhas e arquivos GPX

---

**🛠️ Stack:** React Native • SQLite • Firebase • Expo

- 📱 Aplicativo nativo multiplataforma
