# 📝 Guia de Personalização do Portfólio

Este guia irá te ajudar a personalizar seu portfólio com suas informações pessoais.

## 🔧 Personalizações Necessárias

### 1. Informações Pessoais
Substitua os seguintes placeholders nos arquivos:

- `[Marcos]` → Seu nome completo
- `pikulitomarkin` → username do GitHub
- `mpadilha932@gmail.com` → Seu email real
- `SEU_PERFIL` → Seu perfil do LinkedIn
- `[Londrina, PR/Brasil]` → Sua localização

### 2. README.md Principal
No arquivo `README.md`, atualize:

- **Seção "Sobre Mim"**: Escreva uma descrição pessoal
- **Projetos em Destaque**: Adicione seus projetos reais
- **Tecnologias**: Ajuste conforme suas habilidades
- **Links**: Atualize todos os links para seus perfis

### 3. Projetos (PROJETOS.md)
- Substitua os projetos de exemplo pelos seus
- Adicione descrições detalhadas
- Inclua capturas de tela se possível
- Atualize categorias conforme necessário

### 4. Habilidades (HABILIDADES.md)
- Ajuste o nível de conhecimento (⭐) para cada tecnologia
- Adicione novas tecnologias que você domina
- Remova tecnologias que não utiliza
- Atualize certificações reais

### 5. Contato (CONTATO.md)
- Adicione seus links reais de redes sociais
- Atualize informações de disponibilidade
- Personalize tipos de projeto que interessam
- Ajuste localização e idiomas

## 🚀 GitHub Pages (Opcional)

Para hospedar no GitHub Pages:

1. **Crie um repositório no GitHub** com o nome `pikulitomarkin` (mesmo nome do seu username)
2. **Faça upload dos arquivos** para o repositório
3. **Ative GitHub Pages** nas configurações do repositório
4. **Seu portfólio estará disponível** em: `https://pikulitomarkin.github.io`

## 🎨 Customizações Avançadas

### Temas para GitHub Pages
Você pode alterar o tema no arquivo `_config.yml`:
- `jekyll-theme-cayman` (atual)
- `jekyll-theme-minimal`
- `jekyll-theme-architect`
- `jekyll-theme-time-machine`

### Badges Personalizados
Crie badges personalizados em: [shields.io](https://shields.io)

### Estatísticas do GitHub
Personalize em: [github-readme-stats](https://github.com/anuraghazra/github-readme-stats)
